# Examples

- [Dream YAM Sim](yam_mujoco/README.md) (`yam-mujoco`): interactive dual-arm MuJoCo simulator with three cameras, natural-language Dream tasks, and local physics tests.

The library's wheel carries each example's scripts and assets (`dream_examples/<name>/`), and `dreamcli example <name>` runs it: `dreamcli example yam-mujoco`. `dreamcli example` alone lists them. From a source checkout, run an example's script in its directory instead, after installing its own requirements. An example's tests and asset tools stay in the repository.
