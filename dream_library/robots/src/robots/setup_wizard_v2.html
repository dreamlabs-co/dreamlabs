    Choose the files you recorded your data with. lerobot-calibrate writes one file per arm. Each arm must match one of these files. If an arm doesn't match, setup won't use it, because your data and your arm would describe different poses.

    Embodiment

It has your arm's joints and the three cameras Dream Labs base models use: one that sees the whole scene and one on each wrist. You choose each camera's role in Set up cameras. Data you upload for a fine-tune goes under this embodiment.

      How setup names adapters

      Each arm connects through a USB adapter. Setup names each adapter by its serial number, so the arms can't swap places after you replug them or restart. If an adapter has no serial number of its own, setup names it by its USB port instead, so keep it in that port.

      Advanced arm settings

      Give each arm a permanent connection name

      When the computer restarts, it can assign can0 and can1 in a different order, which swaps the left and right arms. This rule names each arm's connection after its adapter's serial number, so each arm keeps the same name.

      Continue without a passing test?
      
    
      If you skip these checks, your robot may not perform as well.
      
    
      
    
      
    
      
  
      
      

  
      
    
      Skip the reach area?
      
    
      Without a reach area, the arms can move anywhere, including into your camera mount. Setting one makes runs safer and more reliable.

      Skip the tool center point?
      
    
      This isn't recommended. Dream-1 positions your gripper by this point, so without it, hand movements may miss their target. Your arm file records that you skipped it, and every start shows a warning.
